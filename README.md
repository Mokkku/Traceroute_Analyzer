# Traceroute_Analyzer
A program to analyze traceroute output.

# Instructions to run
To run the traceroute analyzer, run ```python3 Main.py``` in the Linux Bash shell on Ubuntu Linux. When prompted ```Input the name of the .pcap file to be analyzed:  ```, type in the .cap file name to test and press enter. To get TTL information on the group trace files, group1-trace#.pcap and group2-trace#.pcap, run ```python3 r2_analyzer.py```.
